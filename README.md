Bienvenido al código fuente de mi portafolio profesional. Este proyecto fue desarrollado para demostrar mis habilidades como Desarrollador Full Stack y Arquitecto Cloud, destacando mi experiencia construyendo sistemas complejos de principio a fin.

## 🛠️ Stack Tecnológico
* **Frontend:** HTML5 semántico, CSS3 puro (con variables CSS globales y arquitecturas Flexbox/Grid) y JavaScript.
* **Diseño:** Patrones de UI/UX modernos, Glassmorphism, y diseño completamente responsivo (Mobile-First).
* **Rendimiento:** Optimización de carga, lazy-loading simulado e implementaciones amigables con SEO.

## 📂 Estructura del Proyecto
- `/css`: Hojas de estilo centralizadas y variables de tema (`styles.css`).
- `/js`: Lógica de interacciones, animaciones de scroll (Intersection Observer) e inicialización de componentes.
- `/pages`: Casos de estudio detallados de mis proyectos profesionales (Sistemas ERP, Portales Web, etc).
- `/assets`: Recursos gráficos y capturas de pantalla de los proyectos.
